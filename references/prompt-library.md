# 通用提示词与穷奇范例

本次图片使用内置 imagegen 生成，并做过一次平涂修订。下面是把实际有效约束合并后的可移植自然语言模板，未在其他模型中实测。无需保留模型专属语法。

## 1. 通用完整模板

替换方括号中的内容，再把整段交给生图模型。没有特殊要求时，可删除相应可变字段。

```text
创作一张[角色名称及身份]的完整单角色彩色造型稿。[身体构造与必须保留的识别特征]。[具体动作、表情与性格]。[视角、画幅和构图]，全身及主要附属部件完整入画，轮廓之间留有清楚的空隙。

20世纪60至80年代中国上海美术电影经典二维手绘动画的美术语言，融合民间年画、戏曲造型与民间漫画的表现力。形体概括，比例适度夸张，剪影辨识度强。眉眼、鼻形、口型和适合该角色的胡须或须毛表达性格。传统元素体现在造型和表演中，不添加无关装饰。细节服从整体大形状，适合逐帧手绘动画。

采用细腻、明确、连贯、富有节奏的墨黑轮廓线，轻微自然粗细变化，外轮廓略重，内部线简洁准确，边缘干净锐利，无墨色晕染或细碎排线。

采用复古矿物色相：[主要颜色及其对应部位]。可从朱砂红、孔雀绿、石青蓝、赭石、土黄、墨黑、象牙白和少量旧金中选择。二维赛璐珞平涂，大面积完整色块，每部位一个均匀底色，最多一至两层形状概括、边界明确的硬边阴影。色块清楚、干净、有秩序，表面平整哑光，无柔和渐变、斑驳笔触、体积高光或复杂碎光。

背景为[简单背景或支撑面]，保持大面积留白。极轻微的旧纸纹理与胶片颗粒只提供年代感，主体轮廓与内部色块保持清楚，不整张泛黄。无文字、标题、签名、标志或水印。
```

## 2. 独立画风模块

这段可以直接放在其他角色描述之后。主体另行描述，避免依赖“穷奇”或其他名称的自动联想。

```text
20世纪60至80年代中国上海美术电影经典二维手绘动画美术设定稿，融合民间年画、戏曲造型与民间漫画的表现力。形体概括、比例适度夸张、剪影清楚，眉眼、鼻形、口型和须毛突出角色性格。细腻明确、有节奏的墨黑轮廓线，轻微粗细变化，外线略重、内线简洁，主体边缘干净锐利，无墨色晕染。复古矿物色相，以朱砂红、孔雀绿、石青蓝、赭石、土黄、墨黑、象牙白及少量旧金构成有限配色。二维赛璐珞平涂，大面积完整色块，每部位一个均匀底色，最多一至两层形状概括的硬边阴影。颜色清楚、干净、有秩序，表面平整哑光，无渐变塑形、体积高光或斑驳笔触。细节服从整体造型，毛发与羽毛概括成几组清楚的大形状。简单浅色背景，大面积留白，极轻微纸纹与胶片颗粒，纹理不损伤主体线条和色块，无文字与水印。
```

## 3. 通用排除项

模型有独立负面提示词栏时放入该栏；没有时加在正向提示末尾。它们辅助明确画法，不能代替正向描述。根据主体删去无关项。

```text
避免：写实毛发和羽毛微纹理，三维渲染，现代光泽动漫，水墨晕染，水彩渗色，厚涂笔触，柔和渐变，体积光，发光特效，复杂高光，密集排线，繁复国潮纹样，过度旧化与污渍，新增肢体或翅膀，文字，标志，水印。
```

## 4. 穷奇完整范例

下面的构造来自本次用户上传参考图的可见形象，不宣称为全部古籍中穷奇的唯一形态。

```text
创作一张穷奇的完整单角色彩色造型稿：有一对巨大鸟类羽翼的虎形异兽，虎身、四足、墨黑虎纹、长而弯曲的虎尾。身体低伏，四足着地，前爪有力地抓住低矮岩台，身体横向展开，头部略朝观者，两翼从肩胛附近自然生长，在背后左右高举展开。横向4:3构图，全身、双翼、爪子和尾巴完整入画，留出边缘空白。

20世纪60至80年代中国上海美术电影经典二维手绘动画的美术语言，融合民间年画的装饰造型与戏曲式性格表情，参考《哪吒闹海》的形体概括和《天书奇谭》的表情表现。保持明确的虎形面孔：斜挑浓眉、警觉的眉眼、宽而简练的虎鼻、上扬露牙的嘴角、清楚的犬齿、少量有节奏的胡须与颊毛，凶猛、狡黠、桀骜。传统戏曲感通过五官与神态表现，不贴完整脸谱。肩胸壮实、腰腹收紧、四肢适度夸张，尾巴形成流畅弧线。双翼概括为两组大扇形，每翼少量清楚的大初级飞羽配两排概括羽片，细节服从剪影。虎纹以少量整齐弧形或楔形墨黑色块顺应躯干。

细腻、明确、连贯、有节奏的手绘墨黑轮廓线，轻微自然粗细变化，外轮廓略重，内部线简洁准确，主体边缘干净锐利，无水墨晕染、密集毛发或细碎排线。

虎身以赭石和土黄为主，虎纹与线条墨黑，腹胸与羽翼象牙白，羽翼局部孔雀绿与石青蓝，口腔和眉眼少量朱砂红。采用复古矿物色相，表面平整哑光。二维赛璐珞平涂，大面积完整色块，每部位一个均匀底色，最多一至两层形状概括、边界明确的硬边阴影。去掉柔和渐变、斑驳笔触、体积高光和复杂碎光，颜色清楚、干净、有秩序。

背景为干净浅象牙白，大面积留白，足下仅一块概括为几个灰青色硬边块面的低矮岩台与少量平面投影。极轻微的旧纸纹理与胶片颗粒主要留在背景，主体轮廓和色块保持清楚，不整张泛黄。不添加龙角、盔甲、衣服、法器、山水云海、装饰边框、文字或水印。
```

## 5. 参考图说明与修订句

提供多张图时，显式加上角色分工：

```text
图1仅作为主体构造与姿态参考，保留[身份特征]，将密集细节概括为适合动画的形状；图2仅作为线条、平涂色块与整体简化程度的风格参考，不复制图2的角色、文字或背景。没有参考图也应按照上述文字构造主体。
```

若实际结果出现水彩质感，可用：

```text
保持主体身份、身体构造、表情、姿态、轮廓和构图不变，只修订上色。每个部位改为一个均匀底色，最多一层形状概括、边界清楚的硬边阴影。去掉柔和渐变、斑驳笔触、毛羽微纹理和体积高光，墨黑轮廓连贯锐利。支撑面也概括为几个完整平涂块面；微弱纸纹只提供背景年代感。不要添加新部件、纹样或文字。
```

若实际结果出现现代卡通式圆润大眼，根据角色改用“小而警觉的眼睛、压低眉骨、紧凑口鼻、简练颊毛”等具体描述。不要无依据地改掉用户已经认可的五官。
